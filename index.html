Data Links

Expects columns: Date, ID; daily Warmup, Agenda, Reminders, Message; sticky Title, Start, End, Roster, EQ, Standards, Resources, Ticker, and optional Color and Style. Blank sticky cells keep the last value for that ID.

Expects columns: Status (ACTIVE to show everyone, TEACHER_ONLY to hide just from Student Mode links while keeping it on your own dashboard), ID, Type, Title, Category, Prompt, Answer, Value. For the Reinforcement Lab (Type=reinforcement), Prompt holds the schedule (FR-5, VR-5, FI-8, VI-8, or RANDOM) and Value holds the round length in seconds.

Theme & Terminology

The board background and Light & Mid Accent follow Primary unless you set the accents yourself. A class's Color column on the schedule sheet replaces Primary while that class is on screen.

A Style column on the schedule sheet can switch this per class.

🎮 Game Settings

📄 Class Recap PDF

Normally offered automatically when a class period ends. Use this to generate one for the currently active period anytime - handy for testing, or if you dismissed the end-of-class prompt earlier.

☁️ Live Sync (optional)

Connects to a small script (Code.gs) on your own spreadsheet so Student Mode devices see your phone status, timer, and notes, and Reinforcement Lab scores reach your scoreboard. Leave blank if you don't use those.

👋 Welcome to Your Dashboard

This dashboard is powered by two Google Sheets that you own and edit — one for your daily schedule/agenda/roster, and one for game content. Until you connect one, you're looking at sample demo data so you can explore safely.

1. Grab the template below, then in Google Sheets go to File → Make a copy.

2. Fill in your schedule, then File → Share → Publish to web, choose CSV, and copy that link.

3. Paste the link into Settings → Data Links and save.
